# Nani Cakes 🍰
<br>

## 📌 Sobre o Projeto

**Nani Cakes** é uma landing page totalmente responsiva para uma doceria. O projeto foi criado para servir como uma vitrine digital, permitindo que os clientes explorem os produtos (cupcakes, bolos, etc.), consultem os preços e iniciem o processo de pedido de forma intuitiva, direcionando o contato para o WhatsApp.

<br>

## ✨ Funcionalidades

  * 📱 **Design Responsivo:** Experiência de usuário consistente em desktops, tablets e celulares, adaptando o layout para cada dispositivo.
  * 🎠 **Carrossel de Produtos Interativo:** Navegação fluida e suave para visualizar os diferentes doces e bolos.
  * 🍔 **Menu Hamburguer:** Menu otimizado para navegação em telas menores, garantindo acesso fácil a todas as seções.
  * 💬 **Contato Direto:** Botões e links que levam o cliente diretamente para uma conversa no WhatsApp, agilizando o processo de encomenda.

<br>

## 🛠️ Tecnologias Utilizadas

  * **HTML5:** Estruturação semântica do conteúdo.
  * **CSS3:** Estilização, Flexbox para layouts flexíveis e Media Queries para responsividade.
  * **JavaScript (Vanilla):** Manipulação do DOM para implementar toda a interatividade, como o menu e o carrossel.
  * **Git & GitHub:** Controle de versão e hospedagem do código.
